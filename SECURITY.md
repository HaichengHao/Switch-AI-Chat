# Security Policy

## Sensitive information

Never include API keys, `config.ini`, private conversation data, device keys, SD-card images, or private logs in an Issue or pull request. Revoke an API key immediately if it has been exposed.

## Reporting a vulnerability

Prefer GitHub private vulnerability reporting or Security Advisories when available. Otherwise, contact the maintainer through the GitHub profile without including secrets in the first message. Do not publish an exploitable vulnerability before a fix is available.

## Supported release

Security fixes target the latest published release. Older NRO builds may not receive patches.
